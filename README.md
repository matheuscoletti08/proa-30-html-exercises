# Exercícios de HTML5 e CSS3

Repositório com 30 exercícios práticos de HTML5 e CSS3, do nível iniciante ao projeto integrador.

## Conteúdo

todos os exercicios estão no [text](<Atividade01 HTML5 CSS3.pdf>)

## Como abrir

Basta abrir qualquer arquivo `.html` no navegador (duplo clique).
Para o projeto final, abra `projeto-final/index.html`.

## Estrutura do projeto final

```
projeto-final/
├── index.html
├── sobre.html
├── contato.html
├── css/style.css
├── js/script.js
└── images/
    ├── logo.png
    ├── banner.jpg
    └── favicon.ico
```
